회귀
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜): 1. baseball sarvant에선 투수의 팔각도가 담긴 csv파일을 fangraph.com에선 선수들의 장기부상이력이 담긴 csv파일을 다운로드 받았다. 투수의 팔각도와 부상간 상관관계를 분석해보기 위해서이다.
2. 독립변수:투수의 팔 각도 종속변수:부상기간 팔각도가 부상에 미치는 영향을 알고 싶었기 때문에 x축에 해당하는 독변수에 투수의 팔각도를, y축에 해당하는 종속변수에는 투수의 부상기간을 지정했다. 3. fangraph.com에서 다운로드 받은 장기부상자 명단에서 우리가 사용할 투수의 데이터를 제외한 데이터를 모두 지웠다. 분석대상이 아닌 데이터를 지움으로써 보고자하는 관계를 더 명확하게 분석하기 위해서이다. 4. 분할 5. 기준선 6. 후보 모델 비교 7. 선택 8. 평가 9. 해석 10. 한계 점검
